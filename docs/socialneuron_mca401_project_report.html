Project Proposal / Synopsis

Title of the Project

SocialNEURON: AI Social Media Content Automation Platform.

Introduction and Objectives of the Project

SocialNEURON is a web based software application designed to help businesses, creators, and marketing teams plan, generate, review, and verify social media content. The platform allows users to define brand details during onboarding, upload or manually create content topics, generate AI assisted drafts, review content, manage email alerts, and maintain a publication history.

The primary objective of the project is to create a practical, scalable, and user-friendly web application that solves the real-world problem of consistent social media content production. The project demonstrates concepts of web development, database management, user authentication, workflow automation, AI integration, file import, email notification, and report-oriented project documentation.

Project Category

The project belongs to the Application Oriented and Database Oriented categories. It is a web based application developed using Python and Django with a relational database backend.

Industry / Client

This project is developed as an academic software development project. The target users are small businesses, founders, content teams, freelancers, agencies, and creators who need a structured system for content planning and review.

Methodology

The project follows an iterative software development approach. Requirements were identified from the workflow of content teams. The system was divided into modules such as authentication, onboarding, topic generation, schedule upload, AI draft generation, review workflow, email integration, contact inquiry, and dashboard reporting. Each module was developed, tested, and improved incrementally based on observed user flows.

Expected Output

The expected output is a working web application where a user can register, define brand profile, generate or upload content topics, create AI generated drafts, approve or reject content, mark published content with verification link, receive email alerts, and manage content history.

Conclusion

SocialNEURON demonstrates a real-world application of software development concepts. It combines database design, web interface design, authentication, file processing, AI integration, task automation, and testing practices to build a functional content automation platform.

Chapter 1: Introduction

1.1 Brief Idea About the Project

SocialNEURON is an AI powered social media content automation system. It helps users move from idea generation to content review and publication tracking in a single web application. A typical user first creates an account, completes onboarding by entering brand information, then uses the dashboard to generate topics, upload Excel schedules, review generated content, and manage published history.

The system is not limited to a single platform. It supports content planning for platforms such as LinkedIn, Instagram, X, Facebook, TikTok, and multiple content types such as post, reel, carousel, story, thread, and short. This flexibility makes the application more suitable for modern social media workflows.

1.2 Objective of the Project

The objectives of SocialNEURON are:

  • To provide a secure user registration and login system.
  • To capture brand profile information such as niche, audience, platforms, tone, and goals.
  • To generate topic ideas using AI according to selected platform and content type.
  • To allow manual topic creation and Excel based bulk schedule upload.
  • To generate AI assisted content drafts using brand voice and topic context.
  • To provide review actions such as approve, reject, regenerate, comment, and mark as published.
  • To send email notifications to configured recipients.
  • To maintain dashboard analytics and history of published content.
  • To collect contact inquiries from the public home page.

1.3 Scope of the Project

The scope includes complete user and content workflow management for a social media automation platform. It covers authentication, onboarding, dashboard reporting, schedule import, topic generation, draft generation, review management, published link verification, email alert routing, contact inquiry submission, and basic administrative management through Django admin.

The system can be extended in future to include direct publishing APIs, advanced analytics, team roles, payment plans, file storage, and deeper AI prompt management.

1.4 Existing System

Many small businesses manage social media content using spreadsheets, messaging apps, manual notes, and disconnected AI tools. In such workflows, topic planning, AI content generation, approval, and publication tracking are spread across multiple tools. This causes duplication, inconsistent brand tone, missed deadlines, and difficulty in tracking approved or published posts.

1.5 Proposed System

The proposed system centralizes the content workflow into one web application. A user can create topics manually, generate AI topics, upload schedules through Excel, run the AI workflow for due drafts, approve or reject generated content, and manually verify published posts. Brand profile information influences the generated content so the output remains consistent with the business identity.

Chapter 5: Implementation

5.1 Introduction

The implementation is carried out using Django. The project contains a main Django project package, application modules, templates, migrations, services, and supporting scripts. The implementation emphasizes readable workflows, secure user handling, and practical integration with AI and email services.

5.2 Process Description

User Authentication Process

Users can sign up with email and password. Passwords are hashed using Django password hashers. Users can login, logout, request a reset link, reset password through token, and change password from the dedicated settings page.

Onboarding and Brand Profile Process

After signup, users enter brand name, niche, target audience, preferred platforms, writing tone, and content goals. This data is used to build a reusable brand voice payload for AI prompts.

Topic Generation Process

The topic generator accepts query, tone, audience, platform, content type, and number of topics. The server calls the content generation service, which prepares a prompt for Ollama and parses returned lines into topic objects. The results are displayed with score, virality, tone, audience, platform, and content type information.

Schedule Upload Process

Users can upload Excel or CSV files containing columns such as date, topic, tone, audience, platform, priority, and post_type. The import service reads the file and creates scheduled draft records.

AI Draft Generation Process

The cron workflow checks today and tomorrow's draft records. If a draft does not already contain generated content, the system generates content using AI, assigns scores, changes status to pending, saves a content item, and sends email notifications to active recipients.

Review and Publishing Process

Users review pending drafts, approve or reject them, regenerate content, add comments, and mark approved content as published by entering a live URL. Published posts appear in the history page.

5.3 Output and Reports

The application produces the following outputs:

  • Dashboard statistics for total, draft, pending, approved, rejected, and published content.
  • AI generated topic ideas.
  • AI generated social media content drafts.
  • Email notifications for review-ready content.
  • Published history with platform, tone, score, and link information.
  • Contact inquiry records for public visitors.

Chapter 6: Testing

6.1 Introduction

Testing verifies that the system works according to the requirements. The project was tested through module level testing, integration testing, user interface testing, form validation testing, and workflow testing.

6.2 Types of Testing Performed

Unit Testing

Individual functions such as password validation, schedule parsing, topic generation parsing, and contact submission handling can be tested independently.

Integration Testing

Integration testing checks whether modules work together. Examples include signup to onboarding flow, topic generation to draft saving, schedule upload to AI generation, and review approval to published history.

System Testing

The complete system is tested as a web application by navigating through all major workflows from login to content publication.

Validation Testing

Form validation checks required fields in contact inquiry, login, signup, reset password, topic creation, schedule upload, and published link entry.

Regression Testing

Regression testing verifies that updates such as contact form, settings page, email recipient deletion, topic platform selection, and score ring fixes do not break older workflows.
